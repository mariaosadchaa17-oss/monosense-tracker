# Rivna — контрольний список продукту

Цей файл фіксує повний обсяг продукту, погоджений для першої production-версії.

## Реалізовано

- [x] Український інтерфейс, світла/темна тема, mobile-first Soft UI.
- [x] Захищені маршрути, Supabase Auth, RLS, WebAuthn/passkeys.
- [x] П’ятиетапний онбординг: рахунки, період, категорії й ліміти, ціль, партнер.
- [x] Рахунки, банки, власники, валюти, кредитний ліміт і грейс-період.
- [x] Курси НБУ, власний курс, переказ/обмін між рахунками та комісія.
- [x] Транзакції, категорії, теги, імпульсивність, поділ чека та фільтри.
- [x] Регулярні витрати: шаблони, нагадування й створення з форми транзакції.
- [x] Місячні ліміти, прогрес, прогноз і push-алерти 80%/100%.
- [x] Аналітика за тижнями/місяцями, категоріями та імпульсивними витратами.
- [x] Накопичувальні цілі, борги й кредити.
- [x] Спільний бюджет, ролі, email/username інвайти та відкликання доступу.
- [x] Журнал змін ключових фінансових сутностей.
- [x] Telegram webhook для команд на кшталт `300 кава`.
- [x] PWA manifest, service worker, install prompt і push-підписка.
- [x] CSV/Excel імпорт та експорт.
- [x] Нижня mobile-навігація: Головна, Аналітика, Рахунки, Операції, Ще.
- [x] Wheel-picker для рахунку, категорії та дати у швидкому внесенні.
- [x] Вбудоване керівництво та форма відгуку.
- [x] Атомарний імпорт і Telegram-введення зі зміною балансу рахунку.
- [x] Перемикання між особистим і спільними бюджетами.
- [x] Доходи та витрати в одній мультивалютній формі.
